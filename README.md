# UnityToolKits

可跨项目复用的 Unity 工具集合。每个工具是一个独立 UPM 包，放在 `Packages/` 下。

## 工具列表

| 包 | 说明 | 状态 |
|---|---|---|
| `com.limbo.curvemotion` | 可视化曲线运动编辑器，导出 JSON 与 DOTween 代码 | 开发中 |

## 安装

在目标项目的 Package Manager 中选择 “Add package from git URL”，填入：

```
https://github.com/Yexinwei/UnityToolKits.git?path=Packages/<包名>
```
